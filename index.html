How to import from TradingView

1
Open the TradingView Trading Panel
At the bottom of any chart, click your broker name (it shows "Paper trading" if you're in paper mode). The trading panel opens at the bottom of your screen.
2
Go to the History tab
Inside the trading panel, click the History tab (sometimes called "Order History"). You'll see a list of all your past fills.
3
Select the right columns
Click the ⋯ three-dots button on the right side of the History tab header. Make sure these columns are checked:
Symbol required
Side required
Qty required
Fill Price required
Closing Time required
Type auto-detects SL/TP ✓
Commission optional
4
Export the file
Click "Export data…" — you'll find it in the same ⋯ menu, or as a download icon. A CSV file downloads to your computer automatically.
1
Open the import flow
Click Log Trade (top right) and then Import CSV at the bottom of the form. Or go to Settings → Import CSV. Or click Paste data to skip the file entirely.
2
Choose your file (or paste)
Select the CSV file you just downloaded. Crema reads the columns automatically.

Paste shortcut: in TradingView's History tab, select all rows (Ctrl+A or Cmd+A), copy (Ctrl+C / Cmd+C), then use Crema's Paste data button and paste directly — no file needed.
3
Crema pairs your fills into trades
TradingView exports individual buy/sell fills, not finished trades. Crema matches them up using FIFO — each buy is paired with the next sell for that symbol, building a complete trade with entry, exit, P&L and hold time.

If you included the Type column: stop-order exits are auto-tagged as your stop loss price, limit-order exits as your take profit. R-multiples calculate automatically.
4
Confirm and review
A summary shows how many fills became how many trades, and whether any positions are still open (those are skipped — export again when closed). Confirm to add them. Re-importing the same file won't create duplicates.
💡
Add the "Type" column for automatic SL/TP detection
This is the most important tip. When TradingView exports a bracket order that hit its stop, the closing fill has Type = "Stop". When it hit the target, Type = "Limit". Crema uses this to auto-fill the stop loss and take profit prices — which means R-multiples are calculated automatically on import, no editing required.
💡
Include "Closing Time" for hold-time analytics
Without timestamps, the hour×day heatmap, hold-time breakdown, and time-of-day report won't have data. Always include Closing Time when exporting.
⚠
"No trades found" after importing
This usually means your positions are still open in TradingView — Crema only imports completed round-trips. Close your trades, then export and import again. Or the Qty/Side/Fill Price columns weren't selected.
⚠
Unknown column format (column mapper appears)
If Crema opens the column mapper, your broker's CSV uses non-standard header names. Use the dropdowns to tell Crema which column is Symbol, Entry, Exit, etc. This works with any broker — MT4, Tradovate, NinjaTrader and others.
⚠
Trades are in wrong direction (long instead of short)
This can happen if the Closing Time column is missing — Crema can't sort fills chronologically and may pair them backwards. Always include Closing Time. If it still happens, open the trade and flip the direction with the Edit button.
